RFL-APP auf PC und Handy installieren

Windows-PC
1. Lade den Windows-Installer herunter: https://github.com/niiklasmea/rfl-mobile-app/releases/latest/download/RFL-APP-Setup-1.3.6.exe
2. Öffne die heruntergeladene Datei „RFL-APP-Setup-1.3.6.exe“.
3. Wähle im Installationsfenster den Zielordner und schließe die Installation ab.

Android
1. Öffne https://niiklasmea.github.io/rfl-mobile-app/ in Chrome.
2. Tippe auf das Menü mit den drei Punkten.
3. Wähle „App installieren“ oder „Zum Startbildschirm hinzufügen“.

iPhone
1. Öffne https://niiklasmea.github.io/rfl-mobile-app/ in Safari.
2. Tippe auf „Teilen“.
3. Wähle „Zum Home-Bildschirm“ und tippe auf „Hinzufügen“.

Veröffentlichung
Änderungen auf dem main-Branch aktualisieren die Handy-Web-App über GitHub Pages. Ein Tag im Format v* baut den Windows-Installer und veröffentlicht ihn als GitHub Release.

Hinweise
- Profilbild, Anzeigename und Darstellung werden auf jedem Gerät separat gespeichert.
- Autostart und minimierter Start sind PC-Funktionen.
